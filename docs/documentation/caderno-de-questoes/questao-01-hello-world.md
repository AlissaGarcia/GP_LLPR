# Questão 01 — Hello, World!

### <i class="fa-play">:play:</i> Contextualização

O famoso _Hello, World!_ (Olá, Mundo!) é um dos primeiros exemplos apresentados a quem está começando a estudar programação. Sua simplicidade faz com que seja utilizado em diferentes linguagens e cursos de computação como uma primeira experiência de escrita e execução de código.

Mas por que começar justamente com uma mensagem na tela? O que existe por trás de uma instrução tão simples?

Antes de escrever qualquer código, precisamos compreender, ainda que de maneira introdutória, como um computador executa tarefas.

> Um computador não interpreta nossas intenções. Ele executa instruções que precisam ser descritas de maneira organizada e compreensível para o sistema. Essas instruções formam **um algoritmo: uma sequência finita e ordenada de passos que busca alcançar determinado objetivo.**

Nesse contexto, o primeiro contato com a programação consiste em compreender como fornecer uma instrução ao computador e observar o resultado de sua execução.

### <i class="fa-hand-fist">:hand-fist:</i> Desafio

{% tabs %}
{% tab title="Questão" %}
Desenvolva um algoritmo capaz de exibir a mensagem: **Hello, World!**
{% endtab %}
{% endtabs %}

A solução deve apresentar a mensagem exatamente como foi solicitada, utilizando uma **instrução de saída.**

{% hint style="info" %}
Como assim "saída??" Bom, em sistemas computacionais temos esses dois conceitos: a **entrada (input)** e a **saída (output)**. Eles representam, de maneira geral, como as informações chegam ao computador e como os resultados do processamento são apresentados. Podemos entender essa relação de forma simples: a entrada corresponde àquilo que fornecemos ao computador, enquanto a saída representa aquilo que ele nos apresenta como resposta.&#x20;

* **Entrada (input):** clicar em um botão, digitar uma palavra no teclado ou enviar um arquivo.
* **Saída (output):** visualizar uma mensagem na tela, receber um resultado de cálculo ou ouvir um som emitido pelo computador.

Na programação, essa mesma lógica **aparece na construção dos algoritmos.** Podemos fornecer dados para que o programa os processe e apresente um resultado.
{% endhint %}

> Desenvolva um algoritmo capaz de <mark style="background-color:$warning;">exibir</mark> a mensagem: **Hello, World!**

"Exibir" aqui nessa questão tem o mesmo sentido que a instrução "Escrever" vai ter no nosso código. <i class="fa-pen-line">:pen-line:</i>

</details>

<details>

<summary>Qual deve ser o <strong>resultado</strong> após a execução?</summary>

Por fim, qual comportamento é esperado que o computador tenha? Qual o resultado final de toda a nossa operação? O que a gente deve ter de **saída**?&#x20;

> Desenvolva um algoritmo capaz de exibir <mark style="background-color:$warning;">a mensagem:</mark> <mark style="background-color:$warning;"></mark><mark style="background-color:$warning;">**Hello, World!**</mark>

### <i class="fa-circle-notch">:circle-notch:</i> Implementação (Pseudocódigo)

```
inicio
    escreva("Hello, World!")
fim
```

### <i class="fa-check">:check:</i> Resultado esperado

```
Hello, World!
```

### O que aprendemos?

Perceba que nem todo problema exige cálculos, variáveis ou estruturas complexas. Uma boa solução é aquela que **atende ao objetivo proposto** de maneira adequada.
