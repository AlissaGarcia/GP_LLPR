# Introdução ao GitHub

## Introdução ao GitHub

Este módulo apresenta o GitHub como espaço de colaboração, versionamento e organização dos materiais do grupo.

### O que você vai aprender

* Diferenças entre Git e GitHub.
* Criação de conta e organização de repositórios.
* Commits, clonagem e atualização de projetos.
* Branches, pull requests e colaboração.
* Markdown, `README.md` e boas práticas de documentação.

### Sequência de atividades

1. Crie e configure sua conta.
2. Explore um repositório do grupo.
3. Faça uma pequena contribuição documentada.

{% hint style="info" %}
Mensagens de commit devem explicar a mudança de forma objetiva. Exemplo: `Adiciona exercício sobre condicionais`.
{% endhint %}
