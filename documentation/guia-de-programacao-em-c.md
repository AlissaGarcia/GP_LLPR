# Guia de Programação em C

## Guia de Programação em C

C é a primeira linguagem do grupo. Este guia apresenta seus fundamentos em uma sequência prática e progressiva.

### Percurso de estudo

1. Configurar o ambiente e entender a estrutura de um programa.
2. Trabalhar com variáveis, tipos, operadores e entrada e saída.
3. Criar decisões e repetições com condicionais e laços.
4. Organizar dados com vetores, matrizes e funções.

### Como estudar

Leia cada conceito, teste os exemplos e resolva os exercícios. Priorize entender cada instrução antes de adaptar um código.

```c
#include <stdio.h>

int main(void) {
    printf("Olá, mundo!\n");
    return 0;
}
```

{% hint style="info" %}
Os exemplos usam nomes claros e soluções curtas. A complexidade cresce gradualmente.
{% endhint %}
